Split-View Modal Attribution Harness

Authorized security research / responsible disclosure only. Tests whether a native modal triggered by this page is misattributed to a legitimate site opened in a split-view pane. This is a neutral research tool — it does not imitate any brand’s UI. Use your own test files; report findings to the relevant vendor.

Setup

Step 1 — set up the split

Right-click → “Open in split view” to open the target, then come back.

Step 2 — trigger the modal

If mode is auto, the right-click on the link above arms a timer. If mode is button (needed for contact/BT/USB/share/display — they require a fresh gesture), tap below after arranging the split.

What to observe

  • Does the modal appear over / ambiguous to the legit pane, so it reads as belonging to the target site?
  • For no-origin modals (file/share/display/color/date) there is nothing tying the modal to this page — pure visual misattribution.
  • For origin modals (contact/BT/USB) — is the origin small/ignorable enough that the split context wins?
  • The log proves this page receives the result (e.g. the uploaded file) — i.e. the data went to the attacker, not the target.
